# Public website boundary

This repository is exclusively the public Simple Silicon marketing website.

- Never copy, import, commit, or publish any source code from the official Simple Silicon desktop application, including excerpts, internal libraries, build artifacts, source maps, or archives.
- Work only with website source and approved public-facing media. Do not access the private application repository to implement website changes.
- Screenshots must not expose private application implementation, credentials, or other confidential content.
- Before publishing, review the exact Git diff and the static artifact. Publish only the website artifact at `simplesilicon-main/dist/client`.
- These rules apply to future maintenance as well as the current task.
